# Свои бланки: фон, шрифт, рамка

Бот умеет собирать бланк из вашей картинки: фон, рамка, свой шрифт и
координаты полей. Пользовательского мастера в Telegram пока нет — бланк
описывается YAML-файлом. Это заготовка: схема и рендер уже работают, UI можно
добавить позже.

## Быстрый старт

1. Скопируйте пример:

   ```bash
   cp config/custom_templates.yaml.example config/custom_templates.yaml
   ```

2. Положите картинки в `assets/` (например, `assets/backgrounds/paper.jpg`) и,
   если нужен свой шрифт, в `assets/fonts/`.

3. Поправьте координаты и запустите проверку:

   ```bash
   python generate_samples.py --check
   python generate_samples.py --debug-boxes     # рамки и подписи поверх бланка
   ```

4. Перезапустите бота (или пришлите владельцу `/reload`). Новый бланк появится
   в карусели и в поиске по словам.

В Docker `config/` копируется в образ: положите файл рядом с `templates.yaml`
до сборки или смонтируйте каталог `config` томом.

Файл `config/custom_templates.yaml` читается вместе с `config/templates.yaml`.
Ключи бланков не должны совпадать: при совпадении побеждает пользовательский
файл.

## Структура файла

```yaml
fonts:
  my_font: assets/fonts/MyFont.ttf

defaults:            # общие значения для всех бланков этого файла
  font: my_font
  font_size: 48

templates:
  my_contract:
    title: "Мой контракт"
    canvas: [1240, 1754]
    background: {...}
    frame: {...}
    dates: {...}
    fields: {...}
```

`fonts` и `defaults` необязательны: можно ссылаться на алиасы из
`templates.yaml` (`serif`, `comic`, `handwriting`, `display`, `emoji`).

## Холст и готовый бланк

- `file: templates/my.png` — готовый бланк. Размер холста берётся из картинки.
- Либо `canvas: [ширина, высота]` + `background` — бланк собирается на лету.
  По умолчанию `1240×1754` (A4 при 150 dpi).

Если указаны и `file`, и `background`, файл считается готовым бланком, а
`background` игнорируется (бот напишет предупреждение в лог).

## Фон

```yaml
background:
  image: assets/backgrounds/paper.jpg
  fit: cover       # cover | contain | stretch
  dim: 0.10        # затемнение, 0..0.9
  blur: 0          # размытие в пикселях, 0..40
```

- `cover` — заполнить холст, лишнее обрезать (по умолчанию);
- `contain` — вписать целиком, поля закрашиваются белым;
- `stretch` — растянуть без сохранения пропорций.

## Рамка

```yaml
frame:
  image: assets/frames/gold.png   # png с прозрачностью, растянется на холст
  # или линии:
  color: "#1b2a4a"
  width: 4        # толщина
  inset: 40       # отступ от края
  gap: 8          # расстояние между линиями при double
  double: true    # вторая линия внутри
  corners: true   # уголки
  radius: 18      # скругление
```

Если указан `image`, остальные поля игнорируются.

## Дата

```yaml
dates:
  box: [780, 105, 370, 60]   # x, y, ширина, высота
  font: serif
  font_size: 27
  color: "#4a5568"
  align: right               # left | center | right
  valign: middle             # top | middle | bottom
  max_length: 40
  format: "Дата: {date}"
```

- `{date}` подставляется из `settings.dates` (часовой пояс и формат).
- Кнопка «📅 Дата» под бланком позволяет вписать дату вручную; слово «авто»
  возвращает автоматическую.
- Дату подписи каждой стороны можно добавить в поле:

  ```yaml
  party1:
    box: [78, 1280, 500, 140]
    date:
      box: [78, 1430, 500, 44]
      font_size: 20
      format: "подписано {date}"
  ```

## Поля и условия

`fields` — то же, что в `templates.yaml`: `label`, `sample`, `box`, стиль
шрифта. Ключи полей — только `[A-Za-z0-9_]`, до 16 символов (они попадают в
`callback_data`).

Блок `terms` включает свободные условия: бот попросит текст и напечатает его в
указанном прямоугольнике. `self_sign_note` — пометка для самоподписи.

## Как это работает внутри

- `app/config.py` разбирает `background`, `frame`, `dates`, `canvas` и
  проверяет, что все прямоугольники влезают в холст.
- `app/render.py` собирает холст (`build_canvas`), кэширует его по mtime
  файлов и рисует дату, условия и подписи.
- Готовый file_id бланка нужен для редактирования сообщений Telegram, поэтому
  картинка с датой один раз загружается в storage-чат и переиспользуется.
- Всё состояние — в RAM: после перезапуска контракты исчезают, бланки
  собираются заново.

## Ограничения заготовки

- Нет мастера в Telegram: файл правится вручную.
- Нет загрузки картинки через бота: файлы кладутся в репозиторий/на диск.
- Нет отдельных наборов бланков для разных чатов: список общий.
- Готовые образцы (`python generate_samples.py`) рисуют бланк целиком, а
  `--debug-boxes` показывает координаты поверх собранного холста.
